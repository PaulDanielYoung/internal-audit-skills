## Internal audit skills

The directory containing this instruction file is the auditor workspace root, including when working below `engagements/`.

Before making audit judgments or producing audit work, read the glossary in `GLOSSARY.md` and relevant requirements in `METHODOLOGY.md` and facts in `ORGANIZATION.md` at that root. Follow documented methodology and consult its referenced sources when needed. Where these files are silent, ask about material gaps before dependent work proceeds.

Use `audit-context` to initialize or update shared context and resolve missing or contested terms. Only that skill edits these three documents. Keep individual audit scope, evidence, process and control detail, and outputs under `engagements/`.
