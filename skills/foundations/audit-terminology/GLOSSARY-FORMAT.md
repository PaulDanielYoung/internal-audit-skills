# GLOSSARY.md Format

## Structure

```
# Glossary

The organization's own audit vocabulary: each term's agreed meaning and the synonyms it displaces. Every skill reads it; only `audit-terminology` edits it.

## Terminology

**Term**:
{One or two sentences stating what it is, not what it does.}
_Avoid_: displaced synonyms, separated by commas

**Term**:
{One or two sentences stating what it is, not what it does.}
_Avoid_: displaced synonyms, separated by commas
```

## Rules

- **Be opinionated.** When multiple words exist for the same concept, choose the preferred term and list displaced synonyms under *_Avoid_*.
- **Keep definitions tight.** Use one or two sentences. Define what the term is, not what it does.
- **Define what needs a shared meaning.** Only include audit concepts whose meaning needs to be consistent across the organization.
- **Group when useful.** Use subheadings under `## Terminology` when natural clusters emerge; a flat list is fine for a cohesive vocabulary.
- **Make the glossary easy to navigate.** Alphabetize subheadings and the terms within each group.
