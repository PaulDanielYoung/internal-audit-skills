# Internal Audit Skills

This project provides skills for conducting audit engagements.

## Language

**Ask skill**:
A skill that answers the auditor's question from the context folder as a reply in the conversation, producing no workspace file.

**Context document**:
One converted policy, regulation, or framework in the context folder, carrying front matter that states its title, description, and effective date.

**Context folder**:
The workspace's `context/` folder, holding everything agents read for organizational and methodological context.

**Context index**:
The context folder's `INDEX.md`, listing every context document and where to find it.

**Criteria source**:
A policy or regulation in the context folder that the organization is held to: management's own criteria in `policies/`, the law's in `regulations/`.

**Document request**:
An individual request for material needed for an audit engagement.

**Document request list**:
The collection of document requests for one audit engagement, with each request tracked individually.

**Request owner**:
The person responsible for providing the material requested in a document request.

**Workspace**:
The folder an auditor works in, prepared by the setup skill, holding the context folder and the engagements.
